# KLUE-RoBERTa를 활용한 한국어 상품 리뷰 속성 기반 감성분석

상품 리뷰에서 **제품 속성과 평가 표현을 추출하고, 속성별 긍정·부정·중립 비율을 분석**하는 프로젝트입니다. [RecommABSA](https://github.com/kevinscaria/RecommABSA)를 참고해 한국어 전처리 과정과 KLUE-RoBERTa 기반 추출 모델을 구현했습니다.

- **유형·기간:** 연세대학교 석사과정 「중급프로그래밍」 3인 팀 프로젝트 / 2024.03~2024.06
- **담당:** 이지환 — 한국어 전처리, 학습 데이터 구성, 모델 학습·평가, 감성분석 파이프라인 구현
- **데이터:** AI Hub 상품 리뷰 15,004건 — 패션 5,000건, 화장품 5,000건, IT 기기 5,004건. 전처리 전 원천 리뷰 수입니다.
- **기술:** Python, PyTorch, Hugging Face Transformers, KLUE-RoBERTa-base, KoNLPy(Okt), Pandas, KNU 감성사전

## 주요 구현

- **한국어 전처리:** 맞춤법 검사, 형태소 분석, 불용어 제거를 적용했습니다. `착용감`이 `착용 + 감`으로 분리되는 문제를 보완하기 위해 Okt 사전을 수정했습니다.
- **속성어 라벨 생성:** 원천 속성명과 리뷰의 단어를 대조해 라벨을 만들었습니다. 예를 들어 `화질 좋다`에서 `화질`에 속성어 라벨을 부여했습니다.
- **감성어 라벨 자동 생성:** 감성어의 위치를 표시한 정답이 없어, 원천 감성 정보와 KNU 감성사전을 대조해 후보를 골랐습니다. 후보가 여러 개이면 문장에서 가장 뒤에 등장하는 단어를 선택했습니다.
- **추출 모델 학습:** `klue/roberta-base`로 속성어와 감성어를 추출하는 모델을 각각 미세조정했습니다. 단어가 서브워드로 나뉘면 첫 서브워드에만 정답 라벨을 부여했습니다.

## 리뷰 분석 과정

1. 리뷰를 전처리한 뒤 **두 모델에 같은 텍스트를 각각 입력**합니다.
2. 각 모델이 추출한 첫 번째 속성어와 감성어를 짝짓습니다.
3. 감성어를 KNU 감성사전과 대조해 긍정·부정·중립을 판정합니다.
4. 속성별로 판정 결과를 집계해 각 감성의 비율을 계산합니다.

감성어 모델에는 대상 속성을 따로 입력하지 않습니다. 한 문장에 여러 속성이 있을 때 각 속성과 평가를 모두 연결하는 기능은 추가 개발이 필요합니다.

갤럭시탭 S6 Lite, 트랙수트, 톤업크림 리뷰에 적용한 결과 이미지는 [output/](output/)에서 확인할 수 있습니다.

## 평가 결과와 한계

학습 노트북의 `test` 데이터에 기록된 결과입니다.

| 평가 대상 | F1-Score |
| --- | ---: |
| 속성어 추출 | 0.968 |
| 감성어 추출 | 0.940 |

**최종 긍정·부정·중립 분류 성능을 나타내는 수치는 아닙니다.** 다음 사항을 수정한 뒤 재평가가 필요합니다.

- 평가용 전처리에도 정답 속성명을 텍스트에 추가·치환하는 코드가 포함돼 있습니다. 정답 정보를 입력에서 제외해야 합니다.
- `seqeval` 평가에 사용한 태그(`O / AT`, `O / B`)가 표준 BIO 형식과 다릅니다. 평가 목적에 맞는 태그와 지표를 적용해야 합니다.
- 학습 중 검증과 최종 평가에 같은 데이터를 사용합니다. 데이터를 분리하고, 자동 생성한 감성어 라벨도 사람이 검수할 필요가 있습니다.

## 다운로드 및 실행

대용량 파일은 **Git LFS**로 관리합니다.

```bash
git lfs install
git clone https://github.com/zzzzhwan2/Aspect_Based_Sentiment_Analysis_using_KLUE-RoBERTa.git
cd Aspect_Based_Sentiment_Analysis_using_KLUE-RoBERTa
git lfs pull
```

다음 순서로 각 폴더의 노트북을 실행합니다.

| 순서 | 경로 | 내용 |
| --- | --- | --- |
| 1 | `codes/preprocessing code/` | 속성어·감성어 학습 데이터 생성 |
| 2 | `codes/model training code/` | 두 추출 모델 학습·평가 |
| 3 | `codes/model test code/` | 리뷰 분석 및 속성별 감성 비율 계산 |

노트북의 Colab·Windows 경로를 사용 환경에 맞게 수정하고, 데이터·모델·사전 경로와 Okt의 Java 환경을 확인해야 합니다. 라이브러리 버전은 고정하지 않았으므로 `datasets.load_metric` 등 기존 API의 호환성도 확인해야 합니다.
